# Bug 修正说明

修正原版游戏里**描述与实际效果对不上**的地方，以及几处**资源 / 外观显示错误**。不新增内容，也不改动你的存档。

## 已修复（8 个包）

1. **招架（链锯剑等近战武器）**
   描述写着「吸收 80% 伤害」，原版实际只吸收 20%。现在按描述生效，真正吸收 80%。

2. **重力枪 / 火焰枪 / 手持火焰枪**
   枪身模型显示成灰白格子（材质没有正确加载）。现在显示正常。

3. **暗黑天使 / 黑色圣堂 战团小图标**
   两个战团的徽记在界面上互换了。现在各自归位。

4. **迅捷（黑色圣堂被动）**
   描述写着「回合开始时有 25% 概率获得 1 点行动力」，原版从不触发。现在会正常触发。由两个独立包实现：补齐 `TurnsLeft` 判定，以及修正 `STAT_Plus1AP` 的每回合 AP 分量。

5. **帝拳 禁卫军（被动）**
   描述写着「受到的伤害降低 20%」，原版实际给成了伤害提高。现在改为真正的减伤。

6. **致残射击（Crippling Shot）**
   描述写着 1%，实际效果是 2%。现在中英文描述都统一为 2%。

7. **帝国之拳精工重型爆弹枪外观**
   Steam 版这把枪的自发光强度为 0，PC EE 版带有发光外观。现在把自发光参数调到与 PC EE 一致，武器模型与贴图本身不变。

## 说明

- 修复只改游戏数据与文本，不修改存档，已保存的进度不受影响。
- 卸载时所有文件都会还原为原版。
- 除外观一项外，其余改动都是让游戏与它原本给出的说明保持一致，不额外调整难度或平衡。
